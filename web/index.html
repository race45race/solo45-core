Template policy

Leave chosen kinds of transactions out of the blocks this pool builds. Watch only counts what a rule would skip (and the fees it would cost); Filter leaves them out. Your node still checks every job, and if a filtered job ever fails that check, the pool mines the node's own template for that block.

Stall guard

If a peer announces a new block but never sends it, your node can sit on the old block for up to 10 minutes. The stall guard disconnects that peer after this many seconds, so the node gets the block from another one.
seconds (20–600, 0 = off)

Stratum V2

An encrypted mining port. Miners that speak Stratum V2, or the Stratum V2 Translator Proxy in front of Stratum V1 miners such as Bitaxes, connect here and check this pool's key, so nobody on the way can read or change their work. Same work, same payout address and same block checks as the Stratum V1 port.
